# Extreme Life

Jogo de mundo aberto original, feito em Godot 4 com ferramentas gratuitas.

## Como rodar
1. Baixe o Godot 4.3 ou mais novo em https://godotengine.org
2. Abra o Godot, clique em **Importar** e escolha o arquivo `project.godot` desta pasta.
3. Aperte **F5** para jogar.

## Controles
WASD andar, Shift correr, Espaço pular, mouse olhar, Esc libera o mouse.

## Regras do projeto
- Só assets próprios ou com licença livre (anote a fonte em `docs/CREDITOS.md`).
- Nomes, marcas e personagens fictícios.
